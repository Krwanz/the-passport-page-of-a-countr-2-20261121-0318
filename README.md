An invented passport spread for the Republic of Talveria, a cold northern
island nation: an open passport with a data page (portrait of Ingrid Marit
Haldorsen of Havnsfjord, machine-readable strip, Talveric/English language
column) and a visas page with consistent entry/exit stamps from neighbouring
Nordavik and Kalvøya — all dated after the passport's issue on 12 MAR 2024 —
plus a red harbour-tax fee stamp and a visa condition (no employment; fishing
permit required north of 62°N).

Entry for the make.fun bounty: https://make.fun/bounty/the-passport-page-of-a-countr-2-20261121-0318

## How it works

`passport.png` is the finished 1024×768 passport spread (under 1 MiB).
`main.ts` copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
